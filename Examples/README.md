# Examples

Every file here is written by the tests — `WRITE_EXAMPLES=1 swift test --filter ExampleTests` — from [sample.md](sample.md), a three-page review with one of everything in it: front matter, four levels of heading, emphasis, links, inline code, a table, a code block, a quote, numbered and task lists, a rule and a figure.

## The five designs

| Design | |
|---|---|
| [report](designs/report.pdf) | Ruled headings, a running title, page numbers. |
| [memo](designs/memo.pdf) | To / From / Date / Re from the front matter. |
| [article](designs/article.pdf) | Serif, centred title. |
| [plain](designs/plain.pdf) | Nothing but the text, set well. |
| [manual](designs/manual.pdf) | Accent band, numbered headings, bordered code. |
